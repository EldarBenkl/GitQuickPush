## Описание

GitQuickPush — расширение для Visual Studio Code, которое помогает быстро отправлять изменения проекта в удалённый Git-репозиторий.

Вместо ручного ввода нескольких команд Git пользователь может выполнить всё через один интерфейс.

## Возможности

- Выбор удалённого репозитория (Remote).
- Выбор локальной или удалённой ветки.
- Ввод сообщения коммита.
- Просмотр изменённых файлов перед отправкой.
- Автоматическое добавление файлов.
- Создание коммита.
- Отправка изменений в удалённый репозиторий.
- Отображение ошибок при работе с Git.

## Используемые технологии

- TypeScript
- Visual Studio Code API
- Node.js
- Git
- esbuild

## Установка и запуск

1. Скачать проект с GitHub.
2. Открыть папку проекта в Visual Studio Code.
3. Установить зависимости:

```bash
npm install
```

4. Собрать расширение:

```bash
npm run compile
```

5. Нажать F5 для запуска расширения в режиме разработки.

## Использование

1. Открыть папку Git-проекта.
2. Нажать `Ctrl + Shift + P`.
3. Найти команду `GitQuickPush: Push Changes`.
4. Выбрать удалённый репозиторий.
5. Выбрать ветку.
6. Ввести сообщение коммита.
7. Проверить список файлов и подтвердить отправку.
